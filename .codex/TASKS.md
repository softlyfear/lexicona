# Активные задачи

Режим работы по прямому запросу пользователя: продолжать до полного согласованного MVP
и закрытия всей очереди замечаний, явной остановки или необходимости внешнего решения.
Долгосрочная цель сессии активирована. После каждого тикета сохранять состояние и продолжать
следующий без отдельного запроса «дальше». Лимиты платформы не считать выполнением задачи.

Принятые тикеты и протоколы — в TASKS-archive.md.

## Очередь нового пользовательского запроса (ещё не активные тикеты)

Следующую карточку открывать только после завершения текущей. Весь новый запрос остаётся
в работе до выполнения всех результатов; закрытие WORDS-001 не означает завершение очереди.
Ниже порядок по зависимостям; точные AC/API фиксируются перед каждым срезом.

1. SPEECH-001 — выбор английского акцента/доступного browser voice и русского голоса
   в настройках, тест звучания; EN-US default. Конкретный voiceURI — preference браузера,
   voiceschanged/fallback/error/cancel/watchdog — общий speech adapter. Автоозвучка
   учебного prompt после явных user gestures «Начать»/«Далее», без штрафа при отказе TTS;
   stop/cancel на выходе, смене пользователя/скрытии. Для cloze только masked prompt,
   русский голос не подставляется вместо английского; физические устройства проверять
   отдельно и честно отмечать недоступные. Новых passive/listening режимов здесь нет.
2. TRAIN-005 — в новых choice-сессиях всегда ровно 6 вариантов (прямой выбор пользователя),
   а не configurable 4/6/8. Сервер исключает неоднозначные/повторные distractors и проверяет
   option по длине сохранённого snapshot: прежние 4-option сессии продолжают работать.
   Обновить ошибки недоступности, UI/клавиши 1–6 и тесты без раскрытия правильного индекса.
   Выполняется после ручного исключения, чтобы расширенный pool учитывал этот флаг.
3. WORDS-004 — подсказки перевода и транскрипции в WordForm из локального индекса выбранного
   FreeDict+WikDict eng-rus 2025.11.23 (CC-BY-SA-3.0); явный выбор подсказки пользователем,
   сохранение ручного ввода,
   attribution/ограничения источника и отсутствие ложного успеха при недоступности.
   Источник выбран в приватном translation-source-selection.json; оркестратор подтвердил
   checksum артефакта и наличие RU/IPA. Пользовательские слова не отправляются внешним API.
   Перед реализацией прочитать source-report и обязательства: отдельный read-only индекс,
   provenance/credits/license notices и ShareAlike для производных данных, честный порядок
   источника без заявления о популярности; discovery не завершает clearance распространения.
   Ошибка/нет результата не мешает ручному сохранению.
   Подсказка существующему слову проходит обычное подтверждение смыслового reset.

Все перечисленные срезы проходят нужных backend/frontend исполнителей, tests, независимое
review и acceptance. Текущие запросы не разрешают деплой/VPS или force push; Git только root.

Один тикет — законченный вертикальный срез.
Статусы: planned → implementation → review → acceptance → done.
Попытка увеличивается при возврате на доработку.
