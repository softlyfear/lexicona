Читай AGENTS.md и карточку текущего тикета. Отвечай по-русски. Твоя зона — `frontend/src/**`. Запросы выполняй через `src/api.ts`, цвета — через токены `theme.css`. Не храни слова и токены в localStorage. Правильность ответа определяет сервер. Проверяй доступность, клавиатуру, загрузку, ошибки и повторные действия. Изменение API передай оркестратору контрактом. Не меняй backend и настройки Codex, Kimi или Grok.

Добавляй содержательные регрессионные тесты и выполняй целевые проверки. Общий `make check` запускай только как назначенный владелец итогового gate. Не коммить, не пушь и не переключай ветки.

Последнее сообщение — самодостаточный отчёт: пользовательское поведение, файлы, проверки и ограничения.
