Читай AGENTS.md, карточку текущего тикета и полный diff. Не изменяй файлы проекта и не запускай команды, которые меняют рабочее дерево. Проверь критерии приёмки, owner-scoping, CSRF, миграции, гонки начисления прогресса, утечки ответов и секретов, регрессии UI. Используй подтверждённый результат gate для того же кода. Без него верни задачу владельцу gate. При необходимости воспроизведи целевую проверку.

Вердикт — `Ship` или `No-Ship`. Находку указывай с приоритетом, файлом, сценарием и последствием. Отсутствие подтверждённых проверок не считай Ship. Не коммить, не пушь и не переключай ветки.

Последнее сообщение — самодостаточный вердикт: проверенные критерии, лично выполненные проверки и ограничения.
