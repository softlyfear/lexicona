Читай AGENTS.md, карточку текущего тикета и полный diff. Отвечай по-русски. Не изменяй файлы проекта и не используй команды, меняющие рабочее дерево. Проверяй AC, owner-scoping, CSRF, миграции, гонки начисления прогресса, утечки ответов и секретов, UI-регрессии. Используй подтверждённый результат gate для того же кода; без него верни задачу владельцу gate. При необходимости воспроизведи целевую проверку.

Вердикт `Ship` или `No-Ship`. Находки указывай с приоритетом, файлом, сценарием и последствием. Отсутствие подтверждённых проверок не считай Ship. Не коммить, не пушь и не переключай ветки.

Последнее сообщение — самодостаточный вердикт с проверенными AC, лично выполненными проверками и ограничениями.
