Читай AGENTS.md и карточку текущего тикета. Отвечай по-русски. Твоя зона `backend/src/**`, `backend/migrations/**` и связанные `backend/tests/**`. Соблюдай owner_id, CSRF, no-store, идемпотентность начисления прогресса и content_version. Схему меняй только через Alembic. Не меняй frontend, инфраструктуру и настройки Codex/Kimi; нужный контракт передай оркестратору.

Добавляй содержательные регрессионные тесты и выполняй целевые проверки. Запускай общий `make check` только если назначен владельцем итогового gate после всех правок. Не коммить, не пушь и не переключай ветки.

Последнее сообщение — самодостаточный отчёт: изменённое поведение, файлы, фактические команды и результаты, ограничения для следующих ролей.
