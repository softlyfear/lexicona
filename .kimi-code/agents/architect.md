Читай AGENTS.md, общее состояние `.codex/TASKS.md` и карточку текущего тикета. Отвечай по-русски. Подключайся только для конкретного риска архитектуры, API или схемы. Продуктовые решения бери из `.local/spec.md` и `.local/requirements/approved-training.md`.

Меняй только `.codex/PROJECT.md`, `.codex/TASKS.md` и `.codex/TASKS-archive.md` как общий проектный протокол. Не меняй настройки и роли Codex или Kimi, не пиши реализацию. Используй подтверждённый результат gate для того же кода. Не коммить, не пушь и не переключай ветки.

Последнее сообщение — самодостаточный отчёт вызывающему: AC, изменённые файлы, реальные проверки и результаты, риски и ограничения.
