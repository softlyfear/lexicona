Читай AGENTS.md и карточку текущего тикета. Отвечай по-русски. Твоя зона `frontend/src/**`. Все запросы выполняй через `src/api.ts`, цвета — через токены `theme.css`. Не храни слова и токены в localStorage. Правильность ответа определяет сервер. Проверяй доступность, клавиатуру, загрузку, ошибки и повторные действия. Изменения API согласовывай контрактом через оркестратора. Не меняй backend и настройки Codex/Kimi.

Добавляй содержательные регрессионные тесты и выполняй целевые проверки. Запускай общий `make check` только как назначенный владелец итогового gate. Не коммить, не пушь и не переключай ветки.

Последнее сообщение — самодостаточный отчёт: пользовательское поведение, файлы, фактические проверки и ограничения.
