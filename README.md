# Lexicona

Личный англо-русский словарь с тренировками. Работает в браузере на телефоне, планшете и
компьютере, у каждого пользователя свой словарь и свой прогресс.

Что уже есть:

- вход по логину и паролю (аккаунты создаёт администратор);
- профиль и самостоятельная смена пароля с завершением прежних сеансов;
- словарь: слово, несколько переводов, транскрипция, пример, заметка, личные теги и фильтр по ним, поиск, озвучка средствами браузера;
- тренировка «выбор из четырёх» в направлениях EN → RU и RU → EN, управление с клавиатуры (1–4, Enter);
- письменная тренировка EN → RU и RU → EN с проверкой ответа сервером;
- cloze EN → EN: ввод пропущенного слова или выражения в собственном английском примере;
- карточки EN → RU и RU → EN с раскрытием ответа и самооценкой;
- показ ответа в выборе и письменной тренировке, пропуск в любом режиме без изменения прогресса;
- своё число слов в занятии или все подходящие слова; отбор по тегам и диапазону прогресса,
  случайный порядок и показ фактически доступного количества;
- прогресс слова с пятью уровнями сложности и возможностью продолжать выше 100%;
- ручное исключение из обучения и возврат с сохранением прогресса, фильтр и сортировка словаря.

## Озвучка

В настройках можно выбрать вариант английского, доступные английский и русский голоса,
обычную или замедленную скорость и автоозвучку вопроса тренировки. По умолчанию включена
автоозвучка с предпочтением американского английского. Настройки сохраняются для аккаунта
в текущем браузере. Кнопки проверки звучания и остановки находятся там же.

Набор голосов предоставляет браузер и операционная система. Если выбранный голос исчез,
приложение объясняет замену; при отсутствии голоса нужного языка текстовые тренировки
остаются доступны. Браузер может запретить автоматический запуск — тогда используйте
кнопку озвучки вопроса. Сетевой голос может передавать текст своему провайдеру; тип сервиса
указан при выборе. Собственного платного TTS-сервиса у приложения нет.

## Локальный запуск

Нужны [uv](https://docs.astral.sh/uv/) и Node.js 22+.

```sh
# API на http://127.0.0.1:8000
cd backend
uv sync
uv run alembic upgrade head
uv run lexicona-admin create-user me --admin
uv run uvicorn lexicona.main:create_app --factory --reload

# в другом терминале: интерфейс на http://localhost:5173
cd frontend
npm install
npm run dev
```

База по умолчанию лежит в `backend/data/lexicona.db`. Путь задаётся переменной `LEXICONA_DATABASE_URL`.

## Проверки

```sh
make install    # воспроизводимая установка из lock-файлов
make check      # tooling: тесты; backend: ruff/mypy/pytest; frontend: формат/lint/test/build (с проверкой типов)
make fmt        # исправление форматирования
```

GitHub Actions вызывает те же цели Makefile на push в main и pull request.
Для отдельной проверки типов доступна команда `npm run typecheck` из `frontend/`.
Итоговый `make check` запускает назначенный владелец после всех правок кода и тестов;
независимый ревьюер использует подтверждённый результат для того же кода.

Правила и конвейер Codex — [AGENTS.md](AGENTS.md), роли — `.codex/agents/`,
текущий тикет — `.codex/TASKS.md`. После открытия доверенного проекта просмотрите
и включите хук через `/hooks`. Хук форматирует файлы после `apply_patch`;
после изменений через shell используйте `make fmt`. Полные проверки — `make check`.
Для архитектора и ревьюера задано семейство Sol с `high`, для четырёх исполнителей —
Terra с `high`. Модель основной сессии и разрешения остаются вашими.
Форматы сверены с официальной документацией: [hooks](https://learn.chatgpt.com/docs/hooks)
и [subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents).

Для wrapper нужны Python 3.11+ и установленный авторизованный Codex CLI; `make install`
их не устанавливает. Для запуска Codex из проекта используйте `./scripts/codex` или
`make codex`: перед запуском
wrapper обновит модели ролей из каталога Codex. Команда `make codex-models` только обновляет
модели; при недоступности каталога остаются текущие. Прямой запуск Codex desktop обходит
wrapper, а уже запущенная сессия автоматически не перезагружается. При появлении новых
версий изменятся отслеживаемые файлы `.codex/agents/*.toml`: это обычный diff для следующего
коммита, скрипт сам не коммитит. Если обновлений нет, файлы не перезаписываются.

## Продакшен

```sh
cp .env.example .env    # указать LEXICONA_DOMAIN
docker compose up -d --build
docker compose exec app lexicona-admin create-user me --admin
```

Caddy сам получает TLS-сертификат для домена. База лежит в volume `data`.

Перед обновлением схемы остановите процесс приложения, сделайте резервную копию SQLite
через Python `sqlite3.Connection.backup()` или команду `sqlite3 .backup`, затем выполните
`alembic upgrade head` и запустите приложение. Для локального запуска путь по умолчанию —
`backend/data/lexicona.db`, в контейнере — `/data/lexicona.db`; проверьте фактический
`LEXICONA_DATABASE_URL`. Не копируйте только основной файл работающей БД: изменения могут
находиться в WAL. Миграция сохраняет слова, переводы и задания; откат с прогрессом выше
100% или новыми состояниями обучения отказывается терять данные.
