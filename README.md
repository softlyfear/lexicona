# Lexicona

Личный англо-русский словарь с тренировками. Работает в браузере на телефоне, планшете и
компьютере, у каждого пользователя свой словарь и свой прогресс.

Что уже есть:

- вход по логину и паролю (аккаунты создаёт администратор);
- профиль и самостоятельная смена пароля с завершением прежних сеансов;
- словарь: слово, несколько переводов, транскрипция, пример, заметка, личные теги и фильтр по любому из выбранных тегов, поиск, озвучка средствами браузера;
- подсказки переводов из локального словаря без знаков ударения, предложения исправления опечаток и автоматический выбор транскрипции с сохранением источника;
- тренировка «выбор из шести» в направлениях EN → RU и RU → EN, управление с клавиатуры (1–6, Enter);
  неправильные варианты дополняются скрытым встроенным словарным пулом без добавления слов в словарь;
- письменная тренировка EN → RU и RU → EN с проверкой ответа сервером;
- сопоставление пар EN → RU в двух колонках группами до восьми однозначных слов и переводов;
  если подходящих слов меньше, показывается доступное количество;
- после первой ошибки в выборе, сопоставлении и письменной тренировке можно отвечать повторно
  без нового штрафа; завершение группы сопоставления не даёт дополнительного прогресса;
- показ ответа в выборе, сопоставлении и письменной тренировке, пропуск в любом режиме без
  изменения прогресса;
- своё число слов в занятии или все подходящие слова; отбор по любому выбранному тегу и диапазону прогресса,
  случайный порядок и показ фактически доступного количества;
- прогресс слова с пятью уровнями сложности и возможностью продолжать выше 100%;
- занятия по внутреннему интервальному расписанию: сначала слова с наступившим сроком повторения,
  затем по желанию до 10 новых; свободная практика не меняет расписание;
- ручное исключение из обучения и возврат с сохранением прогресса, фильтр и сортировка словаря.

## Озвучка

В настройках можно выбрать вариант английского, доступные английский и русский голоса,
обычную или замедленную скорость и автоозвучку вопроса тренировки. По умолчанию включена
автоозвучка с предпочтением американского английского. Настройки сохраняются для аккаунта
в текущем браузере. Кнопки проверки звучания и остановки находятся там же.

Набор голосов предоставляет браузер и операционная система. Если выбранный голос исчез,
приложение объясняет замену; при отсутствии голоса нужного языка текстовые тренировки
остаются доступны. Браузер может запретить автоматический запуск — тогда используйте
кнопку озвучки вопроса. Сетевой голос может передавать текст своему провайдеру; тип сервиса
указан при выборе. Собственного платного TTS-сервиса у приложения нет.

## Установка на телефон или планшет

Установка на телефон или планшет: откройте сайт по HTTPS и перейдите в настройки,
раздел «Установка приложения». Android Chrome может показать системную кнопку установки;
на iPhone/iPad в Safari используйте «Поделиться» → «На экран Домой». После установки
Lexicona открывается отдельным приложением, для работы требуется интернет.

## Локальный запуск

Нужны [uv](https://docs.astral.sh/uv/) и Node.js 22+.

```sh
# API на http://127.0.0.1:8000
cd backend
uv sync
uv run alembic upgrade head
uv run lexicona-admin create-user me --admin
uv run uvicorn lexicona.main:create_app --factory --reload

# в другом терминале: интерфейс на http://localhost:5173
cd frontend
npm install
npm run dev
```

База по умолчанию лежит в `backend/data/lexicona.db`. Путь задаётся переменной `LEXICONA_DATABASE_URL`.

Для подсказок один раз выполните из корня проекта `make dictionary`. Команда скачивает
закреплённый архив FreeDict+WikDict eng-rus 2025.11.23 (около4 MB), проверяет SHA256
и атомарно создаёт отдельный индекс. Уже скачанный архив можно использовать без сети:

```sh
cd backend
uv run --locked python -m lexicona.dictionary build --archive /path/to/freedict-eng-rus-2025.11.23.src.tar.xz
```

Индекс по умолчанию — `backend/data/dictionaries/eng-rus-2025.11.23.sqlite3`;
`LEXICONA_DICTIONARY_PATH` задаёт другой путь. Процесс приложения должен иметь право
чтения. При отсутствующем или повреждённом индексе ручное добавление слов работает.
Словарь содержит отдельные слова и готовые устойчивые выражения, но не переводит произвольные
фразы. Порядок вариантов соответствует источнику и не означает популярность. Знаки ударения
из русских переводов удаляются. IPA не размечена по акцентам: форма предпочитает вариант
с US-признаками `oʊ`, `ɹ/r/ɚ/ɝ`, а без них берёт первый доступный без гарантии диалекта.
Исходные credits, лицензия и преобразования сохранены в README и `/api/dictionary/notices`.

Если локальный словарь ничего не нашёл, можно включить машинный EN→RU перевод через DeepL Free
и Gemini Free API. Настройки читаются из корневого `.env` и при запуске из корня, и из `backend/`.
По умолчанию используется DeepL; при его сбое или отсутствии ключа вызывается Gemini, если его
ключ настроен. `LEXICONA_TRANSLATION_PROVIDER=gemini` выбирает Gemini напрямую. Примеры переменных
есть в `.env.example`; `LEXICONA_GEMINI_MODEL` позволяет переопределить модель. Введённый текст
передаётся DeepL, а при fallback — также Gemini, только при пустом локальном результате. Gemini
возвращает до трёх переводов и сгенерированную US IPA, которая подставляется автоматически.
Кнопка «Добавить пример» отдельно отправляет в Gemini введённое EN-слово или выражение и заполняет
английский пример с русским переводом. После генерации можно дополнить поля ещё одной EN/RU-парой
через пустую строку или заменить все примеры. При повторной генерации прежние EN-примеры передаются
Gemini с требованием изменить ситуацию, грамматическую конструкцию и лексику; точный повтор не
подставляется. Сохранение происходит только вместе со словом.
Без ключей внешние запросы отключены, локальный словарь и ручной ввод работают. Машинный перевод
и IPA подписаны как результат внешнего сервиса, не получают источник FreeDict и не гарантируют
качество идиом, транскрипции или примеров. Google может использовать контент бесплатного тарифа
Gemini для улучшения своих продуктов, поэтому не отправляйте через него приватный текст.

## Проверки

```sh
make install    # воспроизводимая установка из lock-файлов
make check      # tooling: тесты; backend: ruff/mypy/pytest; frontend: формат/lint/test/build (с проверкой типов)
make fmt        # исправление форматирования
```

GitHub Actions вызывает те же цели Makefile на push в main и pull request.
Для отдельной проверки типов доступна команда `npm run typecheck` из `frontend/`.
Итоговый `make check` запускает назначенный владелец после всех правок кода и тестов;
независимый ревьюер использует подтверждённый результат для того же кода.

Правила и конвейер Codex — [AGENTS.md](AGENTS.md), роли — `.codex/agents/`,
текущий тикет — `.codex/TASKS.md`. После открытия доверенного проекта просмотрите
и включите хук через `/hooks`. Хук форматирует файлы после `apply_patch`;
после изменений через shell используйте `make fmt`. Полные проверки — `make check`.
Для архитектора и ревьюера задано семейство Sol с `high`, для четырёх исполнителей —
Terra с `high`. Модель основной сессии и разрешения остаются вашими.
Форматы сверены с официальной документацией: [hooks](https://learn.chatgpt.com/docs/hooks)
и [subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents).

Для wrapper нужны Python 3.11+ и установленный авторизованный Codex CLI; `make install`
их не устанавливает. Для запуска Codex из проекта используйте `./scripts/codex` или
`make codex`: перед запуском
wrapper обновит модели ролей из каталога Codex. Команда `make codex-models` только обновляет
модели; при недоступности каталога остаются текущие. Прямой запуск Codex desktop обходит
wrapper, а уже запущенная сессия автоматически не перезагружается. При появлении новых
версий изменятся отслеживаемые файлы `.codex/agents/*.toml`: это обычный diff для следующего
коммита, скрипт сам не коммитит. Если обновлений нет, файлы не перезаписываются.

### Kimi Code

Kimi Code работает как второй независимый агент и не изменяет настройки Codex. Его роли находятся
в `.kimi-code/agents/`, hook форматирования — в `.kimi-code/hooks/`. Для запуска основного
оркестратора используйте `make kimi` или `kimi --agent lexicona-orchestrator`. Роли наследуют
модель основной Kimi-сессии. Общие TASKS/PROJECT остаются проектным протоколом обоих агентов.

Hook Kimi подключается в пользовательском `~/.kimi-code/config.toml` через `PostToolUse`;
машинный `local.toml` не коммитится. Как и для Codex, обязательной проверкой остаётся `make check`.

## Продакшен

```sh
cp .env.example .env    # указать LEXICONA_DOMAIN
docker compose up -d --build
docker compose exec app lexicona-admin create-user me --admin
```

Caddy сам получает TLS-сертификат для домена. База лежит в volume `data`.
Сборка образа получает закреплённый словарный архив; отдельный индекс входит в образ
и читается из `/app/dictionaries`, вне пользовательского volume.

Перед обновлением схемы остановите процесс приложения, сделайте резервную копию SQLite
через Python `sqlite3.Connection.backup()` или команду `sqlite3 .backup`, затем выполните
`alembic upgrade head` и запустите приложение. Для локального запуска путь по умолчанию —
`backend/data/lexicona.db`, в контейнере — `/data/lexicona.db`; проверьте фактический
`LEXICONA_DATABASE_URL`. Не копируйте только основной файл работающей БД: изменения могут
находиться в WAL. Миграция сохраняет слова, переводы и задания; откат с прогрессом выше
100% или новыми состояниями обучения отказывается терять данные.
